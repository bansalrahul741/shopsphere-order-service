# ShopSphere – Order Service

## 1. Overview
The Order Service manages customer orders within the ShopSphere e-commerce application.

It is an independently developed microservice that communicates with the Product Service to retrieve product information and validate product details when creating orders.

## 2. Business Responsibilities
- Create customer orders.
- Retrieve order details.
- Retrieve customer order history.
- Update order status.
- Cancel orders.
- Communicate with the Product Service.

## 3. Technology Stack
- Python 3.13
- FastAPI
- PostgreSQL
- SQLAlchemy
- HTTPX
- Docker
- Kubernetes
